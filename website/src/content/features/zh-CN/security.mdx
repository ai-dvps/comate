每个工作区独立配置 Provider 凭据。工具请求可暂停并等待选择 **允许**、**始终允许** 或 **拒绝**；Bot 角色进一步限制文件、会话记录、命令和 Skill 访问。策略可以降低风险，但不能替代组织自身的安全审查。
