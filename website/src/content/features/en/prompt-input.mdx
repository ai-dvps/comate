The input grows with content and supports `/` to trigger the skill/command picker and `@` to trigger file references. Resolved skills and workspace files become lightweight chips, so they cannot be partially edited by accident. To replace one, delete the whole chip with Backspace or Delete, then use `/` or `@` again. Prompt history can be fuzzy-searched and quickly refilled. Switch between Enter-to-send and Ctrl/Cmd+Enter-to-send, with IME composition protection.
