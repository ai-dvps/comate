---
question: Where does data go, and how are tool permissions controlled?
order: 3
---

Data boundaries depend on the model Provider you choose, enabled Skills or MCP services, and organization-configured integrations. Comate does not claim that data never leaves the device: task content may be sent to services you explicitly configure. Sensitive tool calls should run only after a transparent permission request; a task pauses and asks for attention when more permission or human input is needed.
