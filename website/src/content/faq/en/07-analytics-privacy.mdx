---
question: What does website analytics collect?
order: 7
---

The site loads Google Analytics only after you explicitly allow it, and uses it only to measure anonymous page visits, download entry points, and navigation to GitHub Releases. Page views carry only the normalized site path; download events contain only locale, CTA location, platform option, and destination stage. Ad storage and ad personalization remain disabled; rejecting does not affect browsing or downloading, and no event contains Session content, Workspace data, or model credentials.
