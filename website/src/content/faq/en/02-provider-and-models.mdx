---
question: Do I need to buy a model service, and which Providers can I choose?
order: 2
---

Comate does not include free inference. You can create a Workspace and draft Session first; running an Agent and completing a task requires model credentials or a configured Provider. Available models depend on the Provider configured by you or your organization. The Agent backend is the task execution engine; the Provider supplies the model service, so they are separate settings. See [Provider setup](/comate/en/usage/#provider-setup).
