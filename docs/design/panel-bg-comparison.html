方案 B：强分层

  • 新增 surface-subtle 和 surface-elevated
  • Prompt Input 用 surface-elevated + 微阴影，更突出
  • 面板之间的深度差异更明显，像原生桌面 App
  • 改动量稍大，需要新增 token 和 Tailwind 颜色映射
主要区别：
  • 方案 A 只调整现有 token 的数值，把 header/status bar/sidebar 都放到 surface 上。看起来更像一个干净的网页版 Chat 界面。
  • 方案 B 给输入框单独加了一层 surface-elevated，并拉大 bg 与 surface 的对比。整体更像 VS Code / Slack 这类原生多面板桌面应用。
