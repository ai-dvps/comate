极简白灰方案

  • Chrome 灰：App Header、Left Sidebar、Status Bar 同一个灰
  • 工作区白：Chat Header、Message Body、Right Panel、Prompt Input 都是白色
  • 分隔：只靠 1px border，不用颜色堆层级
  • 输入框：白色 + subtle border/shadow，自然融入工作区但又有边界
