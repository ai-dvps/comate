新层级方案

  • App（最上层）：App Header + Status Bar
  • Workspace（中间层）：Left Sidebar + Chat Header + Right Panel
  • Session（最底层）：Message Body
  • Session Card：Prompt Input 等需要浮起的卡片
当前 token（问题） 
--color-bg:      40 20% 96%  / 0 0% 5%
--color-surface: 40 15% 98% / 0 0% 8%

bg 与 surface 差距太小，且语义上无法表达 App/Workspace/Session 三层。

建议 token 
/* Light */
--color-app:          0 0% 100%;
--color-workspace:    220 10% 98%;
--color-session:      220 14% 94%;
--color-session-card: 0 0% 100%;

/* Dark */
--color-app:          220 14% 13%;
--color-workspace:    220 16% 10%;
--color-session:      220 18% 6%;
--color-session-card: 220 15% 8%;
组件映射（按新层级）
区域层级推荐 token理由
App HeaderApp--color-app全局导航，最顶层
Status BarApp--color-app与 App Header 呼应，形成上下框架
Left SidebarWorkspace--color-workspaceWorkspace 级导航/文件树
Chat HeaderWorkspace--color-workspace当前 Session 的元信息，属于 Workspace→Session 过渡
Right PanelWorkspace--color-workspace当前 Session 的辅助面板，与 Sidebar 同级
Message BodySession--color-session主内容区，视觉上最"后"
Prompt InputSession Card--color-session-card在 Session 内需要浮起，便于定位
